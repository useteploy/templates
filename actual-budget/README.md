# Actual Budget

Envelope (zero-based) budgeting with a local-first web/desktop client and an
encrypted sync server. Deploy:

    teploy template install actual-budget --server <name> --var domain=budget.example.com

First visit sets the server password, then create your budget. Bank sync is
optional: connect a SimpleFIN Bridge account (simplefin.org, $15/yr, covers
US + Canadian banks) under Settings, or import CSV/OFX exports for free.
